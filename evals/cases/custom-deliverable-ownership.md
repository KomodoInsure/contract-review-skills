# Case: ownership of a custom deliverable built under an SOW

Read `_provider-context.md` first; it is part of this packet.

**Deal:** Enterprise customer (US commodities trader). Subscription $300,000 per year. New SOW ($60,000): Provider will build a custom transformation library that converts the customer's proprietary trade-ticket formats. Provider will build it on its standard transformation engine and reuse generic parsing components it already owns.

**Playbook excerpt (IP and outputs):**
- Customer may own outputs Smart Mapping generates for it, as between the parties.
- Deliverables built specifically for one customer under a paid SOW may be assigned to the customer, excluding Provider's pre-existing materials, the Service and general know-how, which Provider keeps and licenses to the customer as needed to use the deliverable.

**SOW redline:**
> [Provider assigns to Customer all right, title and interest in the Deliverables, including all components, tools and code used to create them.]

**Ask:** Verdict, driver and counter language.
