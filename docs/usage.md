# Using the skill

Supply the agreement and incorporated documents, the party you represent, the business objective, the current negotiation stage, and any approved positions or playbook. Specify the deliverable: issue memo, anchored proposed edits, counterparty-ready language, or native tracked changes using a capable document tool.

Examples:

> Use contract-review. We represent the service provider. This is a close round: preserve the approved fees, liability caps and IP allocation. Resolve the new change-order language and identify any dependent clauses that need repair. Return proposed edits, external rationales and internal decisions separately.

> Use contract-review. We represent the customer. The deployment now includes affiliates and an external maintenance provider. Substantial changes are authorized to make those uses and transition workable. Preserve the supplier's standalone IP. Review the whole packet and identify evidence still needed.

> Use contract-review to compare the order, MSA and DPA. Explain which actual conflicts the precedence clauses resolve, and distinguish missing documents from confirmed omissions.

The root skill routes to references for SaaS, services, NDAs, liability, indemnity, IP, data and confidentiality. It is not a substitute for a company playbook. Add your approved positions to the task; hypothetical examples in the skill are not your organization's policy.

The skill does not send negotiations, approve exceptions or accept terms. Native Word redlining depends on the host's available document tools. Text proposals alone are not a tracked-change artifact. Current-law conclusions require appropriate research and professional judgment.
