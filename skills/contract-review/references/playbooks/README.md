# Playbooks

Each playbook covers one recurring SaaS or AI negotiation ask: what to read first, what drives the decision, common market positions (context, not policy), a fill-in company position, and a worked example. Load every playbook whose trigger appears in the request or redline.

| Ask or provision | Playbook |
| --- | --- |
| New or broadened increased-liability categories (negligence, breach of law, misrepresentation, "failure to perform") | [liability triggers](liability-triggers.md) |
| Indemnities removed from the cap, separate indemnity caps, breach-of-agreement indemnities | [indemnity caps](indemnity-caps.md) |
| Breach costs as direct damages, data-breach supercaps, fines and penalties | [data breach costs](data-breach-costs.md) |
| Carveouts from the consequential-damages exclusion (lost data, cost of cover) | [damages exclusion carveouts](damages-exclusion-carveouts.md) |
| Insurance clauses, additional insureds, "confirm your insurance covers this" | [insurance alignment](insurance-alignment.md) |
| Liability for implementation or professional services; on-site injury and property | [services liability](services-liability.md) |
| No-training commitments, "improve the Service", derived, usage and aggregated data | [AI training and data use](ai-training-and-data-use.md) |
| Model or LLM vendors as subprocessors; retention, notice and veto | [AI model subprocessors](ai-model-subprocessors.md) |
| Customer AI-use addenda: disclosures, model audits, regulatory classification | [customer AI addenda](customer-ai-addenda.md) |
| IP indemnity for AI-generated outputs | [AI output indemnity](ai-output-indemnity.md) |
| Ownership of outputs, fine-tunes, templates and "learnings" | [AI output ownership](ai-output-ownership.md) |

| SLA targets, credits as sole remedy, chronic-failure termination | [SLA and credits](sla-and-credits.md) |
| Purchase-order, portal and click-through terms; customer paper | [customer paper and PO terms](customer-paper-and-po-terms.md) |
| Assignment, change-of-control consent and termination | [change of control](change-of-control.md) |
| Deleted or narrowed customer indemnity | [customer indemnity](customer-indemnity.md) |

Worked examples use a fictional provider and fictional policies. Apply a playbook's company position only when the user supplies it; otherwise label proposals as negotiating positions.
